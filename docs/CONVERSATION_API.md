# Conversation API Documentation

This document describes the Conversation API endpoints for managing conversations and messages in the PlotMix service.

## Authentication

All conversation endpoints require authentication. Include the JWT token in the Authorization header:
```
Authorization: Bearer <your-jwt-token>
```

## Base URL

```
/api/conversations
```

## Endpoints

### Conversations

#### Create Conversation
- **POST** `/api/conversations`
- **Description**: Create a new conversation
- **Request Body**:
  ```json
  {
    "title": "Optional conversation title",
    "projectId": "Optional project ID to associate with"
  }
  ```
- **Response**: Returns the created conversation object

#### Get User Conversations
- **GET** `/api/conversations`
- **Description**: Get all conversations for the authenticated user
- **Query Parameters**:
  - `page` (optional): Page number for pagination (default: 1)
  - `limit` (optional): Number of conversations per page (default: 10)
  - `projectId` (optional): Filter conversations by project ID
- **Response**: Returns an array of conversation objects

#### Get Conversation
- **GET** `/api/conversations/:conversationId`
- **Description**: Get a specific conversation with all its messages
- **Response**: Returns the conversation object with messages included

#### Update Conversation
- **PUT** `/api/conversations/:conversationId`
- **Description**: Update conversation details
- **Request Body**:
  ```json
  {
    "title": "New conversation title"
  }
  ```
- **Response**: Returns the updated conversation object

#### Delete Conversation
- **DELETE** `/api/conversations/:conversationId`
- **Description**: Delete a conversation and all its messages
- **Response**: Success message

#### Get Conversation Stats
- **GET** `/api/conversations/:conversationId/stats`
- **Description**: Get statistics about a conversation
- **Response**: Returns conversation statistics including message counts and types

### Messages

#### Add Message
- **POST** `/api/conversations/:conversationId/messages`
- **Description**: Add a new message to a conversation
- **Request Body**:
  ```json
  {
    "content": "Message content",
    "messageType": "user", // Optional: "user", "llm", "system", "canvas_generation", "error"
    "attachments": [ // Optional
      {
        "id": "attachment-id",
        "name": "file-name",
        "type": "file-type",
        "size": "file-size",
        "url": "file-url"
      }
    ],
    "options": { // Optional
      "webSearch": true,
      "audio": false,
      "music": false
    }
  }
  ```
- **Response**: Returns the created message object

#### Get Messages
- **GET** `/api/conversations/:conversationId/messages`
- **Description**: Get messages from a conversation
- **Query Parameters**:
  - `page` (optional): Page number for pagination (default: 1)
  - `limit` (optional): Number of messages per page (default: 50)
  - `before` (optional): Get messages before this timestamp
- **Response**: Returns an array of message objects

#### Get Message
- **GET** `/api/conversations/messages/:messageId`
- **Description**: Get a specific message
- **Response**: Returns the message object

#### Update Message
- **PUT** `/api/conversations/messages/:messageId`
- **Description**: Update message content
- **Request Body**:
  ```json
  {
    "content": "Updated message content"
  }
  ```
- **Response**: Returns the updated message object

#### Delete Message
- **DELETE** `/api/conversations/messages/:messageId`
- **Description**: Delete a specific message
- **Response**: Success message

## Message Types

The system supports the following message types:

- `user`: Messages sent by the user
- `llm`: Messages generated by the AI/LLM
- `system`: System messages
- `canvas_generation`: Messages related to canvas generation
- `error`: Error messages

## Error Responses

All endpoints return consistent error responses:

```json
{
  "success": false,
  "message": "Error description",
  "error": "Detailed error information"
}
```

Common HTTP status codes:
- `200`: Success
- `201`: Created
- `400`: Bad Request
- `401`: Unauthorized
- `404`: Not Found
- `500`: Internal Server Error

## Examples

### Creating a conversation and adding messages

```bash
# Create a conversation
curl -X POST /api/conversations \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"title": "My New Conversation"}'

# Add a user message
curl -X POST /api/conversations/<conversation-id>/messages \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"content": "Hello, how are you?"}'

# Get all messages
curl -X GET /api/conversations/<conversation-id>/messages \
  -H "Authorization: Bearer <token>"
```

## Security Notes

- Users can only access their own conversations
- All operations are logged for audit purposes
- Message content is validated and sanitized
- Rate limiting may be applied to prevent abuse
